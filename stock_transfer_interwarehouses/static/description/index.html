STOCK TRANSFER INTERWAREHOUSES

 

Stock transfer interwarehouses module is to support the stock transfer process between warehouses belonging the same company.

Stock Transfer Documents provide with an overview of all the activities performed in the stock transfer process; therefore, it is possible to control all the stock transfer process steps in only one document.

The stock transfer process has been implemented as follows:

·       A stock transfer document has to be created in a draft status detailing the responsible user, source and destination warehouses, document date and requested receipt date;

·       A notification could be sent out to the responsible user (mail or a message in the inbox) for requesting their approval; the stock manager permission is needed for approving stock transfer document;

·       System check is performed for guaranteeing whether source and destination warehouses are allowed as per the current warehouses settings where the resupply chain has been defined;

·       Goods movements are created accordingly the current warehouses setting, i.e. how many steps are involved in the incoming shipment process for the destination warehouse and in the outgoing shipment process in the source warehouse;

·       Quantities to deliver, Quantities delivered and Quantities received are monitored at item level

·       When the first deliver has been performed, the stock transfer document status is automatically set as in progress (the stock transfer process is running and the document cannot be cancelled anymore);

·       When no pending goods movement exist, the stock transfer status is set automatically as done (the stock transfer process has been performed, the stock in transit is empty, so the document is closed).

·       As described above, the source warehouse has to the set as resupply one in the destination warehouse setting

·       Both ‘In Progress’ and ‘Done’ statuses are set automatically accordingly the current stock transfer process status

·       Archive feature has been activated

·       It is possible to delete it only in cancel status

·       Calendar view is provided

·       Odoo standard activity feature has been activated
