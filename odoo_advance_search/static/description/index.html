Odoo Advance Search | Quick Search

This application will help you to filter quickly and easily on list/tree view.

Key features:
  • Quick search section over all list/tree view.
  • Apply immediately when you hit Enter or focus out from any quick search fields.
  • Perform multiple search queries over Many2one fields. (Ex.: Customer is Gemini Furniture or Lumber Inc)
  • Date range filter for date and datetime type of fields.
    • Filters can work with the group by.
